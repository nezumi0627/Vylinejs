# 作者とクレジット {#authors-and-attribution}

Vylinejs は [nezumi0627](https://github.com/nezumi0627) が保守しています。
[LINEJS](https://github.com/evex-dev/linejs) から派生したフォークであり、上流のコード、API 構造、必要な MIT ライセンスの表示を保持しています。

LINEJS では、開発者として [Piloking](https://github.com/piloking)、[EdamAme-x](https://github.com/EdamAme-x)、[MocA-Love](https://github.com/MocA-Love)、[Hafusun](https://github.com/hafusun) などが挙げられています。
現在の保守担当者は、[上流の README](https://github.com/evex-dev/linejs#authors) を参照してください。

一部のプロトコル機能は、独立して開発された [Vyline](https://github.com/nezumi0627/vyline) および [tqmane/vyline-api](https://github.com/tqmane/vyline-api) の実装も取り入れています。
該当するクレジットと MIT ライセンス条項は、リポジトリと配布パッケージに保持されています。

## 不具合の報告と貢献 {#report-a-problem-or-contribute}

不具合の報告や機能の提案には、[Vylinejs の Issue テンプレート](https://github.com/nezumi0627/Vylinejs/issues/new/choose)を使用してください。
ランタイムとそのバージョン、使用したパッケージのバージョン、最小限の再現手順、実際の LINE アカウントで検証したかどうかを記載してください。
パスワード、トークン、セッションファイル、E2EE の秘密鍵データは含めないでください。
