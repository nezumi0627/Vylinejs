# 質問とサポート {#questions-and-support}

このフォークについての質問は、[Vylinejs の Issue トラッカー](https://github.com/nezumi0627/Vylinejs/issues)に投稿してください。
該当する場合は、不具合報告または機能リクエストのテンプレートを選んでください。

上流の LINEJS に関する質問は、[LINEJS リポジトリ](https://github.com/evex-dev/linejs)と、そこに記載されたコミュニティへのリンクを利用してください。
上流と Vylinejs では、保守担当者、リリース、Issue トラッカーがそれぞれ異なります。

問題を報告する際は、次の情報を含めてください。

- Vylinejs のバージョン、ランタイム、OS、端末プロファイル。
- 認証情報を取り除いた、動作を再現できる最小限のコード。
- 毎回失敗するかどうか、および実際の LINE アカウントや端末を使用したかどうか。
- トークン、機密情報を含む URL、アカウント識別子、メッセージ内容を取り除いた、関連するエラーのテキスト。

セッションファイル、認証トークン、パスワード、E2EE 鍵データ、非公開のチャット内容は添付しないでください。
貢献の方法は[作者とクレジット](./authors.md)を参照してください。
