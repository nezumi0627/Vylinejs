# Questions and support

Use the [Vylinejs issue tracker](https://github.com/nezumi0627/Vylinejs/issues) for questions about this fork. Choose a bug report or feature request template when one applies.

For upstream LINEJS questions, use the [LINEJS repository](https://github.com/evex-dev/linejs) and its community links. Upstream and Vylinejs have separate maintainers, releases, and issue trackers.

When reporting a problem, include:

- Vylinejs version, runtime, operating system, and device profile.
- The smallest code sample that reproduces the behavior, with credentials removed.
- Whether it fails every time and whether a real LINE account/device was used.
- Relevant error text with tokens, URLs containing secrets, account identifiers, and message content removed.

Never attach session files, auth tokens, passwords, E2EE key material, or private chat content. See [authors and attribution](./authors.md) for contribution guidance.
