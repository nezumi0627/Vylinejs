# Authors and attribution

Vylinejs is maintained by [nezumi0627](https://github.com/nezumi0627). The project is a downstream fork of [LINEJS](https://github.com/evex-dev/linejs), and retains upstream code, API structure, and required MIT notices.

LINEJS lists [Piloking](https://github.com/piloking), [EdamAme-x](https://github.com/EdamAme-x), [MocA-Love](https://github.com/MocA-Love), and [Hafusun](https://github.com/hafusun) among its developers. See the [upstream README](https://github.com/evex-dev/linejs#authors) for its current maintainer list.

Some protocol features also adapt independently developed work from [Vyline](https://github.com/nezumi0627/vyline) and [tqmane/vyline-api](https://github.com/tqmane/vyline-api). Their original attribution and MIT terms are preserved in the repository and package distributions where applicable.

## Report a problem or contribute

Use the [Vylinejs issue templates](https://github.com/nezumi0627/Vylinejs/issues/new/choose) for bugs and feature requests. Include the runtime and version, relevant package version, a minimal reproduction, and whether the behavior was tested against a live LINE account. Never include passwords, tokens, session files, or private E2EE key data.
